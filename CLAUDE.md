# Soccer Analyser — заметки и план

Цель: максимально сильная вероятностная модель прогнозов футбольных матчей.
Главное правило проекта: **каждый новый фактор включается только если улучшает
метрики в walk-forward бэктесте** (сначала на валидационных сезонах, потом
подтверждение на отложенном тесте).

## Окружение

- Python 3.12 (winget, user scope) → `.venv` в корне; пакет `soccer` установлен editable (`pip install -e .[dev]`).
- Git установлен через winget (может потребоваться новый терминал, чтобы `git` появился в PATH).
- Команды (из корня проекта):
  - дашборд: `.venv\Scripts\streamlit run app.py` (или превью `dashboard` из `.claude/launch.json`)
  - бэктест: `.venv\Scripts\python scripts\run_backtest.py --seasons 2023 2024 2025 --run-id <id>`
  - тюнинг: `.venv\Scripts\python scripts\tune.py dc|elo --seasons 2019 2020 2021 2022`
  - живые прогнозы + результаты: `.venv\Scripts\python scripts\update.py`
  - тесты: `.venv\Scripts\python -m pytest -q`

## Архитектура

```
soccer/
  config.py        лиги (E0, SP1, I1, D1, F1), сезоны с 2005/06, пути
  data.py          загрузка football-data.co.uk → data/raw/<лига>/<сезон>.csv, нормализация,
                   коэффициенты (приоритет: Pinnacle closing → Avg closing → … → opening)
  probability.py   матрица счетов (Пуассон + поправка Dixon-Coles), рынки: 1X2, тоталы, ОЗ, точные счета
  models/
    dixon_coles.py DC + временное затухание + гауссов приор (MAP) + Лаплас-апостериор
    elo.py         Elo с учётом разницы мячей + порядковая логит-модель → 1X2
  metrics.py       log loss, RPS, Brier, accuracy, ECE, диаграммы надёжности
  calibration.py   VectorScaling (пост-калибровка, пока не включена — см. ниже)
  backtest.py      walk-forward (переобучение еженедельно), бенчмарк = букмекеры
  simulation.py    Монте-Карло остатка сезона с неопределённостью параметров
  storage.py       SQLite data/predictions.db: runs / predictions / results
  pipeline.py      обучение продакшн-моделей, запись живых прогнозов
  tuned.py         ТЕКУЩИЕ гиперпараметры (меняются только по итогам бэктеста)
app.py             Streamlit: Матч · Таблица и симуляция · Рейтинги · Точность
scripts/           run_backtest.py, tune.py, update.py
tests/test_core.py включая тест на отсутствие заглядывания в будущее
```

## Методология

- **Walk-forward**: для каждой недели тестового сезона модель обучается только на матчах
  строго до понедельника этой недели. Elo обновляется пакетами по датам. Тест
  `test_walk_forward_has_no_lookahead` проверяет это: подмена будущих результатов
  не меняет прошлые прогнозы.
- **Разбиение**: валидация (тюнинг) — сезоны 2019–2022; отложенный тест — 2023–2025.
  Тест не используется для выбора параметров.
- **Метрики**: основная — log loss 1X2; также RPS (стандарт для футбола), Brier, ECE,
  log loss тотала 2.5. Сравнение моделей только на общих матчах.
- **Бенчмарк**: вероятности букмекеров (закрывающие коэффициенты, маржа снята
  пропорционально). Это «потолок», к которому стремимся; цель — догнать/обогнать.
- **Байес**: DC-параметры — MAP-оценка с гауссовым приором; апостериор аппроксимируется
  по Лапласу (информация Фишера + точность приора). Используется для апостериорно-
  предиктивных вероятностей в дашборде (`n_samples=300`) и в Монте-Карло сезона.
- **Новички лиги**: приор атаки/обороны промоутированной команды центрирован на среднем
  вылетевших команд (как в Elo), со сдвигом `newcomer_shift` и силой `newcomer_ridge_mult`.
  Состав участников сезона известен заранее, поэтому передаётся в модель без утечки.

Другие идеи для проверки:
- второй дивизион (E1, SP2, I2, D2, F2) в обучении → лучшие оценки новичков
- ежедневное переобучение вместо еженедельного (`--freq D`)
- апостериорно-предиктивные вероятности (`n_samples>0`) в бэктесте
- разное домашнее преимущество по командам; эпоха без зрителей (2020/21)
- тай-брейки по личным встречам (Испания, Италия) в симуляции

## Известные ограничения

- football-data.co.uk обновляет текущий сезон с задержкой в несколько дней; fixtures.csv
  содержит только ближайшие ~неделю матчи (в будни топ-лиг там может не быть).
- Монте-Карло игнорирует поправку ρ (на таблицу почти не влияет) и тай-брейки по личным встречам.
- Elo не даёт тоталов — только 1X2.
